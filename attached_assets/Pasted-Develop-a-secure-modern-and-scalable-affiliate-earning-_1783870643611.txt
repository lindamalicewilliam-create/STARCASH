Develop a secure, modern, and scalable affiliate earning web application called StarCash. The platform should enable users to earn referral commissions by inviting new members to join using their unique referral links. The application should feature a clean, responsive user interface, robust authentication, secure payment tracking, and an intuitive dashboard for both users and administrators.

User Registration & Account Activation

Create a registration system where users can sign up by providing:

Full Name
Username
Email Address
Phone Number
Password & Confirm Password
Referral Code (optional)
Activation Coupon Code (required)
Account Activation
Every new user must enter a valid activation coupon code during registration.
The coupon code must be verified against the database before the account is activated.
If the coupon code is invalid or has already been used, registration should not be completed.
Once verified, the user's dashboard is activated immediately.
Welcome Bonus

After successful account activation:

Automatically credit the new user with a $1 Welcome Bonus.
Display this amount in the Referral Wallet.
Record the transaction in the user's transaction history.

Example:

Transaction:
Welcome Bonus
+$1.00
Status: Successful
